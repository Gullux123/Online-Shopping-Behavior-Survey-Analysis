# Online-Shopping-Behavior-Survey-Analysis
Survey-based data analysis project exploring online shopping behavior, advertisement influence, and platform trust. Data collected via Google Forms and analyzed using Power BI to visualize trends, user preferences, and trust factors across e-commerce platforms.

## Survey Instrument (Google Form)

The survey was designed and distributed using Google Forms to collect responses related to online shopping behavior, advertisement influence, and platform trust.
